# Gnarly Gorilla Sportsbooks

Personal sports-bet tracker for Chrome, including the ASUS Chromebook CX15.

This is not Pikkit. It does not log into sportsbooks, sync accounts, or place bets. You enter the slip. The page stores it in this browser only.

## Run it

1. On GitHub: Settings → Pages → Branch `main` / root → Save.
2. Open https://cwaggoner.github.io/gnarly-gorilla-sportsbooks/
3. Bookmark that page on the Chromebook.

Local file open also works. Export CSV before clearing site data.

## What it tracks

- American odds, stake, units (default $10), result
- Profit, ROI, record, by sport, book, and bet type
- Pending slips
- CSV export and import
